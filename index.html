1. Теориялық бөлім

Көлденеңінен іздеу (Breadth-First Search, BFS) — граф шыңдарын деңгей-деңгейімен, бір қадамнан екінші қадамға біртіндеп айналып өтуге арналған алгоритм.

Өмірден мысал. Сіз үлкен лабиринтте немесе қаланың бейтаныс көшелерінде жүрсіз. BFS әдісімен алдымен тұрған жеріңізге тікелей қосылған барлық көршілес көшелерді шығасыз, содан кейін ғана екінші деңгейдегі алысырақ көшелерге өтесіз. Бұл суға тас тасталғанда толқынның жан-жаққа дөңгеленіп таралуына ұқсайды.

Кезек (Queue). BFS кезекті пайдаланады. Ол FIFO қағидатымен жұмыс істейді: бірінші келген — бірінші кетеді.

Visited. Бір шыңға қайта бармау үшін қаралған шыңдар visited жиынына тіркеледі.

Қолданылуы. Өлшенбеген графта ең қысқа жолды табу, әлеуметтік желіде ортақ достарды анықтау, лабиринттен шығу жолын табу.

from collections import deque

def bfs(graph, start_node):
    visited = set()
    queue = deque([start_node])
    visited.add(start_node)
    order = []
    while queue:
        current = queue.popleft()
        order.append(current)
        for neighbor in graph[current]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    return order

2. 1-тапсырма: Python

Төмендегі граф үшін 1 шыңынан бастап BFS орындаңыз. Шыңдардың айналып өту ретін шығарыңыз және кезекке элементтердің қалай қосылып, қалай алынатынын print арқылы экранға шығарыңыз.

Нәтиже осында шығады.

Нәтижені 1–2 сөйлеммен түсіндіріңіз: кезек пен visited қалай өзгеріп отырды?

3. 2-тапсырма: сәйкестендіру

A) Шыңның бұрын қаралып, тексерілгенін не тексерілмегенін сақтайтын логикалық мәндер жиыны.
B) Графтағы әрбір шыңды деңгей бойынша, жақын көршілерінен бастап тізбектей аралап шығу әдісі.
C) «Бірінші келген — бірінші кетеді» (алғашқы кірген элемент бірінші шығады).
D) Шыңдарды кезектілікпен сақтап, кезек ретімен өңдеуді қамтамасыз ететін деректер құрылымы.
